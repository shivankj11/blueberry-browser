# Blueberry Browser

This fork implements enhanced source attribution for Blueberry Browser answers.

### Source Attribution & Text Highlighting

- **LLM Response Citations**: AI-generated responses now include inline source citations that reference the specific web content used to formulate each answer

- **Interactive Source Display**: Sources are displayed at the bottom of each AI response

- **Text Highlighting**: Implemented highlighting that connects AI responses to their source text. When we can find  cited content, the corresponding source material is highlighted, enabling rapid verification and context exploration

### Demo Video

A quick video demonstration (`.mp4` format) is included in the repository showcasing the citation and highlighting functionality.
